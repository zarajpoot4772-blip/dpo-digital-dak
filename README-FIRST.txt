DPO DIGITAL DAK — QUICK START

For local Windows testing:
1. Extract the latest ZIP.
2. Install Node.js 20 or newer.
3. Double-click RUN-DPO-SYSTEM.bat.
4. Open http://localhost:3000 if it does not open automatically.
